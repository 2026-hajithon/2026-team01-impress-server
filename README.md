# 2026-team01-impress-server

## 커밋 컨벤션

| 태그         | 설명                 |
| ---------- | ------------------ |
| `feat`     | 새로운 기능 추가          |
| `fix`      | 버그 수정              |
| `docs`     | 문서 수정              |
| `style`    | 코드 포매팅 등 코드 스타일 변경 |
| `design`   | 사용자 UI 디자인 변경      |
| `test`     | 테스트 코드 추가 및 수정     |
| `refactor` | 코드 리팩토링            |
| `build`    | 빌드 파일 및 의존성 수정     |
| `ci`       | CI 설정 파일 수정        |
| `chore`    | 기타 자잘한 수정          |
| `rename`   | 파일 또는 폴더명 변경       |
| `remove`   | 파일 또는 폴더 삭제        |

### 커밋 메시지 작성 형식

```text
태그: 변경 내용
```

### 작성 예시

```text
feat: 방 생성 API 구현
fix: 중복 닉네임 검증 오류 수정
docs: API 명세 업데이트
refactor: 참여자 조회 로직 분리
```
